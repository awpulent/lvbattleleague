LVBL Stream Overlay
====================

Setup:
1. Drop this "overlay" folder next to your StreamControl "sc" folder
2. Edit config.js and set your OVERLAY_API_KEY
3. In OBS, add a Browser Source pointed to scoreboard.html
   - Width: 1920, Height: 1080
   - Check "Local file" and browse to scoreboard.html
4. Run StreamControl as normal — the overlay reads streamcontrol.json
   and enriches it with player stats from the LVBL database

What it shows:
- Player names and scores (from StreamControl)
- Character icons for each player's most-played characters
- Head-to-head record between the two players
- Player stats cards (record, winrate, season rank, main character)

The overlay only calls the API when player names change, not every poll.
All stats come from the LVBL database automatically.

File structure:
  overlay/
    scoreboard.html   - OBS browser source (point OBS here)
    config.js         - Your API key and settings
    README.txt        - This file
  sc/
    StreamControl.exe - The existing control app
    streamcontrol.json - Auto-generated by StreamControl
